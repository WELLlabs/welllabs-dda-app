# Overview

The Water Security Toolbox, developed by [WELL Labs](https://welllabs.org/) and [Environmental Defense Fund](https://www.edf.org/), offers science-based resources for designing and evaluating rural water security interventions. It follows a sequential logic of diagnose, design and assess, structured as three frameworks, each supported by a digital tool.

- [Problem Diagnosis Framework](./problem-diagnosis)
- [Solution Design Framework](./solution-design)
- [Monitoring, Evaluation and Learning (MEL) Framework](./mel)
