# Problem Diagnosis Framework

The Problem Diagnosis Framework helps identify priority objectives for a watershed. The digital tool brings together 19 secondary datasets for a selected watershed boundary, explaining:

- What each dataset indicates
- How to interpret it
- Where the limitations lie

1. Users log questions and hypotheses against these datasets, then push them to a mobile app (QField) for field verification.
2. Once field data is collected, it flows back into the web tool, where users validate, reject or refine hypotheses to identify root causes and set landscape objectives.
