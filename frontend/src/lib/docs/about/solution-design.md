# Solution Design Framework

The Solution Design Framework matches these validated objectives to local hydrological and social constraints using a digital tool – Solutions Basket. The tool:

- Provides structured access to knowledge that would otherwise require years of experience to accumulate
- Ensures that technical feasibility is assessed consistently
- Creates a record of the logic behind solution selection
- Enables faster, more informed decision-making

It hosts the collated knowledge of over a 100 solutions that are implemented across rural India. It currently focuses on hardrock typologies but will be updated in the future. The solutions span:

- Supply- and demand-side
- Governance solutions

The tool has built-in GIS functionality, allowing a user to visualise the solutions in suitable landscapes.
